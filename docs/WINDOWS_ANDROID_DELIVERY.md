## 另一台旧电脑：首次接入一次

手机更新页实际报告1号电脑“当前版本尚不支持统一更新，需首次安装新版”。它缺少远程更新接口，需要在该电脑执行以下本地步骤：

1. 将交付目录中的 `PhoneDeck-Enrollment-STAGING.zip` 复制到那台电脑，解压到单独的新文件夹。
2. 结束语音输入，并关闭手机共享麦克风。
3. 在解压目录双击 `Install-UpdateSupport.cmd`。如提示路径，输入那台电脑**原来的PhoneDeck控制台文件夹**，不要输入新解压目录。
4. 脚本备份并替换两个EXE，保留原设备身份和配置。完成后重新开启共享麦克风，并从手机检查该电脑的版本和更新状态。

该ZIP是旧设备接入候选，尚未在那台电脑实际运行；它不适用于没有旧安装的新电脑。不要复制另一台电脑的data。手机3号条目目前提示需重新配对，未自动删除该条目。
