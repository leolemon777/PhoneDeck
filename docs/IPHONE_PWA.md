# iPhone / 安卓手机网页预览

2026-10-03。言渡的手机网页可从 Safari / Chrome 打开，也可添加到主屏幕，无需上 App Store。它属于新 Desktop `2.0.0-alpha.1` 路线；需要使用**包含本次网页功能的新源码构建包**，之前的 Android APK 或旧 Desktop 候选不会自动增加此入口。正式分发和真机验收状态以 [HANDOFF](HANDOFF.md) 为准。

首页提供极简居中、单手底座、紧凑面板三种布局，以及暖纸、墨色、松绿、淡紫、陶土、雾蓝六套配色。点击「界面」切换；正在录音、启动或收尾时，先结束语音再换布局。Goal、退格、回车始终作用于已确认的当前电脑。Goal 发送 `/goal` 并回车；退格每次只删除前一个字，网页没有长按清空。

## 使用前准备

- 手机与电脑位于可互访的同一局域网。选择一台平时保持运行的电脑作为**主电脑**：手机网页由它提供，发给其他电脑的声音也由它转发。即使当前输入目标是另一台电脑，主电脑仍需保持开启、联网并运行言渡。
- 所有参与电脑都使用新版统一 Desktop 接收端，完成本地语音模型准备和系统所需的输入权限。三种必需能力为 `builtInSpeechV1`、`phoneStopV1`、`audioStopV1`；缺失时界面提示更新，不回退到旧控制方式。
- 本网页不连接旧 Windows/Mac Typeless 接收端，不需要 Typeless 或虚拟声卡。Android 原生客户端继续保留，网页不会覆盖手机已安装的 App。
- 使用仍受支持的 Safari / Chrome。真实 iOS、安卓版本与具体手机尚待下方验收；桌面 WebKit 检查不等于 iPhone 已通过。

新 Desktop 的安装、模型和电脑权限说明见 [DESKTOP_QUICK_START](DESKTOP_QUICK_START.md)。该文档中原生 Android 的扫码及证书说明不代替下列网页首次连接流程。

## 第一次连接主电脑

1. 在主电脑启动新版言渡，打开它的本机控制页；通常是 `http://127.0.0.1:8765/`。找到「iPhone / 手机网页」。
2. 展开「首次使用：建立安全连接」，点「下载这台电脑的公开证书」。通过隔空投送或文件传到自己的手机。只安装自己主电脑提供的公开证书，并核对控制页显示的 SHA-256 指纹；不要传输电脑的数据目录或私钥。
3. **iPhone**：打开证书文件，在系统设置中安装下载的描述文件。随后到「设置 → 通用 → 关于本机 → 证书信任设置」，对这个根证书启用完全信任。手动安装描述文件本身不会自动建立 SSL 信任，见 [Apple 官方说明](https://support.apple.com/en-sg/102390)。
4. **安卓**：在系统安全设置中安装 CA 证书，按系统提示完成。不同品牌、系统版本的入口不同。安装后用 Chrome 访问下一步提供的地址。
5. 在主电脑点「连接手机网页」，用 iPhone 的 Safari 或安卓 Chrome 打开二维码对应的手机地址。若二维码选中了手机无法访问的网卡，可展开「改用链接连接」，选择同一局域网的地址。默认地址形如 `https://电脑的局域网地址:8768/phone/`；以控制页实际生成的地址为准。
6. 核对电脑和手机显示的校验码，在主电脑点「确认这台手机」。未确认前，手机应显示等待连接，不能开始录音。一次性链接失效或超时后，重新在电脑开启配对；不要将链接转发给其他人。
7. 手机显示已连接并且电脑语音就绪后，点击话筒，允许浏览器使用麦克风。权限只在主动开始说话时请求。

如果浏览器仍提示证书错误，先检查信任设置、地址和电脑证书；不要把「继续访问不安全页面」当作麦克风已经可用。普通 HTTP 局域网地址不满足网页采音条件。主电脑更换网络地址、证书或数据目录后，重新按电脑控制页检查入口；不要假定之前的主屏幕地址会自动迁移。

## 添加到手机主屏幕

- **iPhone**：在 Safari 中打开已连接的网页，轻点「分享 → 添加到主屏幕」。如显示「作为网页 App 打开」，保持开启，然后添加。步骤以 [Apple 的 iPhone 使用手册](https://support.apple.com/en-lamr/guide/iphone/iphea86e5236/ios) 为准。
- **安卓 Chrome**：打开浏览器菜单，选择「安装应用」或「添加到主屏幕」，实际菜单名称取决于浏览器版本和安装条件。
- 从主屏幕首次打开若再次显示未配对，请在主电脑重新生成手机连接链接，回到**主屏幕里的言渡**，点「电脑 → 连接这台手机」，粘贴完整链接并在电脑确认。不要只回到 Safari 标签页配对：Safari 与主屏幕 App 的存储可能独立。链接需来自当前页面所在的同一台主电脑；网页不会跨地址代为发送凭据。不要在隐私浏览中建立长期入口。
- 添加到主屏幕不提供锁屏后台录音能力，也不意味着电脑离线时可以识别。界面和主题可保存在当前浏览器；连接、授权和语音仍需要主电脑。

## 添加第二、第三台电脑

1. 保持主电脑运行，在另一台新版 Desktop 的本机控制页找到「原生手机 / 添加另一台电脑」。
2. 点「显示配对二维码」，记录下方的局域网电脑地址，再点「复制配对资料」。这里复制的是一次性配对 JSON，不是主电脑的网页链接。
3. 在手机网页点「电脑 → 添加另一台电脑」，分别填写那台电脑的局域网地址和配对资料。地址填写 IP，例如 `192.168.1.20`；不要填写本机 `127.0.0.1`，也不要添加 `http://` 或网页路径。
4. 请求连接后，在**那台电脑**核对并确认。成功前不会把它伪装成在线设备。第三台电脑按相同步骤添加。
5. 轻点设备列表中的一台在线电脑，等待其确认后，顶部的输入目标才改变。录音中不能切换目标。电脑名称与稳定身份对应，不能仅凭 IP 相同认作原电脑。

手机只需为主电脑建立浏览器 HTTPS 信任；主电脑对其他电脑使用配对资料中的证书指纹进行连接校验。当前通过填地址添加，没有在网页里扫描局域网或自动猜测电脑。

设备列表可「移除」另一台电脑，再重新添加失效的配对；录音或目标切换期间不能移除。这里移除的是本网页的关联，不等于在远端撤销所有手机授权。主电脑不能从这个列表移除。

## 三种说话方式

| 方式 | 如何开始 | 如何结束 | 电脑与手机的关系 |
|---|---|---|---|
| 按住 | 先确认当前电脑，再按住大话筒 | 正常松开结束本段；触摸取消会取消本次 | 电脑先停止时，手机也结束本次采音，继续按着不会复活旧会话 |
| 点击 | 选择当前电脑，点一次话筒 | 再点一次；启动中再次点击可取消 | 电脑手动停止本次听写后，手机同步停录，按钮恢复空闲 |
| 共享 | 勾选共享组，切到共享，再手动开启话筒 | 每台电脑用自己的快捷键结束本段；手机话筒关闭全部共享 | 一台电脑停止自己的转写，手机继续为共享组供音，其他电脑仍可接着触发 |

共享模式下，手机会区分「供音中 · 待命」「正在转写」「尚未供音」和离线状态。切到共享这一项不会自动开麦。各台电脑的快捷键从它自己的设置读取；手机不把某一台电脑的键位写死给其他电脑。

**关闭共享前，先用电脑快捷键结束需要保留的那一段。手机关闭共享会取消电脑上尚未结束的转写，避免关闭整组时意外输入未完成内容。** 已经由电脑正常结束的段落保留。

本轮网页的共享用于向多台电脑供音，**不含 Android 原生端的最终文字同步管理、多电脑设置编辑或完整自定义快捷键编辑**。识别后的文字及自动填入仍由对应电脑处理，遵循该电脑的焦点与权限保护。

## 前台、流畅度和触感

- 录音时请保持言渡在前台。切换 App、锁屏或网页离开前台会结束本次采音；返回页面后手动重新开始。共享模式同样如此，不宣称浏览器可持续锁屏供音。
- 网页尝试在录音时保持屏幕唤醒，浏览器不支持或系统拒绝时不能保证屏幕常亮。不要把这一点当作后台录音能力。
- iPhone 网页不强制调用系统触感。支持振动 API 的浏览器可以开启轻触反馈；不支持时明确显示说明，仍保留按压和回弹动画。「减弱动态效果」启用时减少动画。
- 使用稳定 Wi-Fi，主电脑能接网线时可减少无线转发的不确定性。音频只在手机采集一份，再经主电脑发送到选中的电脑。最终文字出现的时间还受到接收电脑的模型、CPU 和语音长度影响，不能用界面响应时间代替识别耗时。
- 默认不保存录音；配对授权与电脑身份不应随安装包一起分发。主题和布局独立于电脑目标。

## 醒来后可以逐项验收

请先从一台电脑、短句开始，再扩展到三台电脑。下列仍需在你的实际 iPhone / 安卓手机与电脑上确认：

1. **初次进入**：证书安装和信任、扫码、校验码、电脑批准、麦克风授权、添加主屏幕后的再次打开。拒绝权限时应有明确提示，不能显示已经采音。
2. **UI**：三布局六主题逐一切换；刘海/灵动岛和底部手势区不遮挡按钮；横竖屏、浏览器地址栏收缩、键盘弹出、大字体、VoiceOver/TalkBack、减弱动态和实际触感逐项查看。
3. **按住**：连续做至少 10 次短按住与正常长句；检查首字、尾字和松开结束。按住未松开时在电脑停止，手机应停录；松手后不能重启旧会话。
4. **点击**：连续开始/结束；开始后立刻从电脑停止；启动中从手机取消；快速结束后再开始新一句。两端应保持同一会话，旧响应不能结束新一句。
5. **三台共享**：勾选三台、手机开启共享。依次在每台电脑用各自快捷键开始/结束，至少轮转三遍；每段只在预期电脑转写。单台结束后手机仍供音，下一台可接着触发。
6. **共享关闭**：先在电脑结束一段，再关闭手机共享，该段应保留；另做一段未结束时关闭手机共享，未结束段应取消，所有供音状态归零。
7. **中断**：在短录音中切换 App、锁屏、断网、退出主电脑。手机不能持续假装在线录音；恢复后不能自动开麦。共享中关闭另一台电脑，其故障不应卡住仍正常的电脑。
8. **基础按键**：在明确的测试文本框中验证 Goal、退格、回车，目标切换确认后只操作新电脑。不要用真实待提交的消息或命令窗口做回车验收。
9. **延迟**：分别记录开始采音、电脑停止后手机停录、松手/点击结束到文字出现的时间；区分 Wi-Fi/连接延迟和本地识别耗时。模拟器或本机回环数字不代表你三台电脑的实际速度。

只有真实设备逐项通过后，才能把对应机型和网络组合记为已验收；目前不将网页预览称为所有 iPhone、所有安卓和所有桌面平台均无问题。
