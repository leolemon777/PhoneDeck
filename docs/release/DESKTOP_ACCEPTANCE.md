# 2.0.0-alpha.1 真机验收

Mac由项目所有者回到电脑后操作。Windows/macOS/Linux的CI构建和公开样本识别已通过；下面检查桌面权限、真实语音和多台物理电脑。每项记录系统版本、芯片、实际结果和错误提示，未操作的项目保持“待验证”。

## Mac首次运行

1. 在“关于本机”确认芯片：Apple M系列用 `osx-arm64`，Intel用 `osx-x64`；系统需macOS14或更新。
2. 解压相应tar.gz，把 `PhoneDeck.app` 放进“应用程序”。退出旧PhoneDeck接收端，然后打开新应用。
3. 预览包为ad-hoc签名；若系统拦截，在“隐私与安全性”按系统提示允许本次打开。不要关闭系统的全局安全检查。
4. 控制页应自动打开；没有打开时访问 `http://127.0.0.1:8765/`。允许本地网络访问；在“辅助功能”中允许安装后的PhoneDeck，授权后退出接收端再重开。
5. 轻量包点击“下载语音模型”，等待校验通过；完整包直接校验。只需下载一次，重开应显示已就绪。
6. Android打开 **Luma Preview**，与Mac连接可互访网络，在“电脑列表”扫码，核对校验码，在电脑确认。若发现失败，输入控制页列出的Mac地址。
7. 手机当前目标选Mac。打开TextEdit空白文稿，分别点击开始/结束和按住/松开，读三句中文（含标点、姓名和数字）。文字应填入该输入框，不能自动回车；取消本段后不能产生结果。
8. 再次开始后切到另一个输入框，结束说话。应只保留结果，不向新焦点填入。
9. 手机开启共享麦克风、勾选Mac。在TextEdit测试 `Control+Option+Space` 点击切换和 `Control+Option+V` 按住；电脑页点击/按住则生成可复制记录。
10. 停止共享、退出手机、撤销配对分别测试一次：采音/对应会话应停止，不能残留按键，不能生成被取消的结果；重开后记录应清空。

新应用后台运行，没有Dock窗口。退出请用控制页底部“退出接收端”；关闭浏览器页不会结束接收端。

## Windows与Linux

- Windows：用安装包在未安装.NET/输入法/虚拟声卡的测试用户中首次安装，按提示允许专用网络；再验收上述扫码、真实中文、取消、焦点改变和共享流程。桌面快捷键为Ctrl+Alt+Space和Ctrl+Alt+V。便携ZIP也应可从含中文和空格的目录启动。
- Linux x64：Ubuntu22.04/24.04先安装deb，用应用菜单打开；记录是X11还是Wayland。X11测试全局快捷键与实际文字填入；Wayland只验收记录、同步与系统自定义切换快捷键，不宣称通用自动填入。GNOME Wayland等环境的普通键注入另列待验证。Mint等其他发行版先作为兼容复核。
- SSH可用于独立目录中的构建、TLS和识别验证；没有桌面登录态的SSH测试不能替代输入焦点与全局快捷键验收。

## 两台或三台物理电脑

1. 每台电脑各扫码一次；手机开启“设置 → 同步文字”，显式勾选共享组，并开启共享麦克风。
2. 在1号电脑用本机快捷键说一句中文，提交后检查各电脑的同一结果编号、来源及文字；换2号电脑再做一次。其他电脑只新增记录，不自动输入或回车。
3. 取消一台电脑的共享组勾选，重开共享，确认新的结果不送到它。关闭文字同步后也应停止转发。
4. 一台接收端暂时退出后重开，在30分钟内检查待同步结果重试，不能重复或形成回传循环。超过30分钟/重启导致内存清空时不保证补发。
5. 手机锁屏和网络断开/恢复分别测试；记录供音和结果实际行为。恢复必须由仍有效的配对和用户开启的共享状态决定，不能自动恢复已取消的听写。

在这些项目完成前，可提供alpha测试包；不把它标成正式稳定版。Windows发布者签名、Mac Developer ID/notarization和稳定分发渠道仍需正式发布前处理。
