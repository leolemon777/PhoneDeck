# UI 翻新：简洁原生方向

用户确认：2026-09-14。当前切片：Android 1.6 开发线 UI 预览。
追加反馈：快捷卡片不显示右上角彩色装饰点；保留发送结果反馈与多电脑输入入口。
Windows 与 macOS 管理界面尚未在本切片实现，不改变已有接收端。

第二轮视觉：参考 Raycast 的克制层级与 Stream Deck 的快捷面板结构，页头缩至 19sp，
取消状态卡和常规按钮的重复边框，快捷键使用 72dp 基准高度/12dp 圆角；普通模式隐藏操作说明。
五台及以下电脑使用同屏等分两行按钮（编号 + 当前/在线/离线），更多电脑继续横向滚动。
语音保持 64dp 主按钮、48dp 退格/回车/模式入口；所有电脑身份、配对和动作配置保留。

## 信息结构

- 顶部固定 PhoneDeck、设置、当前电脑全名和独立连接摘要。点击连接卡打开所有电脑；刷新按钮只做重新探测。
- 中部为可滚动三列纯文字快捷键，名称优先，键位为次级信息；保留编辑、排序、连续按键与确认反馈。
- 底部保留语音模式、主按钮、退格/回车、电平、结果、采音状态和目标编号。
  使用真实测量高度而非 362dp 占位。大字体下底部区域独立滚动，横屏双栏。
- 设置分为使用偏好、连接与维护；按用户追加要求下线九套经典主题，只提供浅色与深色。
- 设备列表/切换继续使用已有 computerId 和健康状态；离线不误发，长按可以管理旧条目。

## 数据与构建边界

- 历史主题 ID 自动迁移至简洁浅/深色；快捷键 schemaVersion=1、配对、语音配置均保留。
- 主题变化只重绑主界面视图，不 recreate 接收/采音状态所有者。
- `UiText` 仅消除前台应用摘要中的缺失/null 展示，不修改协议或电脑名称。
- `:app:assembleUiPreview` 生成 `com.codex.phonedeck.preview`，标签“PhoneDeck UI 预览”。
  独立数据，可与原版并存；默认开发签名，禁止用于 fleet 更新或冒充原渠道升级。
- Preview 运行的仍是真实业务代码；没有伪在线设备或伪识别结果。连接与麦克风操作仍需真实配对和用户授权。

## 验证清单

开发构建、Debug 单测、Lint、UI Preview 构建；浅色/深色首页和全部设置子页，编辑/按键选择/更新页面；
滚动时电脑状态与语音区不丢失；字体放大、横屏、长设备名、离线与空状态；
主题切换后的会话、点击/按住、翻译/问答、20 轮语音真实识别另列硬件验收。
