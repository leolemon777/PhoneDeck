## 2026-10-01 多主题与多电脑配置（当前切片）

用户明确要求「多主题，多电脑配置」，覆盖此前只有两主题的限制。Android `2.0.0-alpha.1` / code4 在「设置 → 外观主题」提供以下六套配色；首页、设置族、原生弹窗/控件及系统栏使用对应令牌。原 `native_light/native_dark` 选择保留，更早主题按明暗迁移。黑白话筒图标及 112dp 圆形语音入口保留。

| 主题 | 稳定 ID | 背景 | 主要操作 |
|---|---|---|---|
| 墨水屏 · 暖白 | `native_light` | #F5F3EE | #242320 |
| 墨水屏 · 深色 | `native_dark` | #1F1E1B | #F1EDE4 |
| 森林 · 松绿 | `forest_light` | #F2F5EE | #2F6346 |

| 天空 · 雾蓝 | `ocean_light` | #EFF4F8 | #365F7E |

主题是手机全局选择，设备切换和电脑设置读取不会覆盖它。新版 Desktop 控制页提供同六套主题，由当前浏览器 localStorage 保留；电脑可各选一套配色，手机与其他电脑不会被同时改色。手机点击/按住模式仍是手机全局偏好，本机点击/按住快捷键则逐电脑配置。

「设置 → 多电脑配置」先列出已配对电脑，再读取所选电脑真实配置。新跨平台接收端分为「语音与快捷键」及「连接与同步」：前者可修改名称、内置识别语言、自动填入与点击/按住快捷键，底部明确「保存到这台电脑」；后者展示已确认连接，并立即保存手机的共享组选择。管理电脑不会切换首页输入目标，地址变化仍归同一 `computerId`。旧接收端继续使用其输入法/连接分页，不显示不存在的内置识别设置。

语音配置通过 `desktopSettingsV1` 的带鉴权接口保存到对应电脑，校验目标、revision、空闲状态和固定候选值。失败、冲突或快捷键不可用保留草稿，提示刷新或停止听写后重试；没有接口的接收端明确提示升级。共享组开关保存在手机且立即生效，同时用于供音与最终文字同步；同步总开关保留在「设置 → 同步文字」，修改组后重开共享麦克风以调整供音范围。

本轮验收应覆盖六主题的首页、设置、主题预览、原生选择弹窗与切换后冷启动；逐电脑读取/修改/保存、目标隔离、revision 冲突、忙碌拒绝、草稿保留、重启保留、共享组与当前目标相互独立。横屏、大字体和语音状态回归分别记录。执行结果见 HANDOFF；Mac/Linux 本机热键、权限、真实输入及不同物理电脑验收仍需真机，不能由自动化配置测试替代。

## 原手机主页面信息结构

- 顶部固定 PhoneDeck、设置、当前电脑全名和独立连接摘要。点击连接卡打开所有电脑；刷新按钮只做重新探测。

- 底部保留语音模式、主按钮、退格/回车、电平、结果、采音状态和目标编号。
  使用真实测量高度而非 362dp 占位。大字体下底部区域独立滚动，横屏双栏。

- 设备列表/切换继续使用已有 computerId 和健康状态；离线不误发，长按可以管理旧条目。

## 数据与构建边界

- 历史主题 ID 自动迁移至简洁浅/深色；快捷键 schemaVersion=1、配对、语音配置均保留。
- 主题变化只重绑主界面视图，不 recreate 接收/采音状态所有者。
- `UiText` 仅消除前台应用摘要中的缺失/null 展示，不修改协议或电脑名称。
- `:app:assembleUiPreview` 生成 `com.codex.phonedeck.preview`，标签“PhoneDeck UI 预览”。
  独立数据，可与原版并存；默认开发签名，禁止用于 fleet 更新或冒充原渠道升级。
- Preview 运行的仍是真实业务代码；没有伪在线设备或伪识别结果。连接与麦克风操作仍需真实配对和用户授权。
