# 言渡 Yandu 2.0 跨平台预览：首次使用

2026-10-03：新版源码增加 iPhone / Android **网页/PWA** 入口，无需 App Store。先完成下方电脑安装、模型准备，手机端改按 [PWA 首次连接指南](IPHONE_PWA.md) 操作：主电脑 HTTPS 8768、公开证书信任、电脑确认配对与主屏幕入口。以下 Android APK 的扫码、文字同步和配置管理说明仅适用于原生客户端；网页当前覆盖三种语音入口、三布局六主题及基础键。浏览器需前台使用，真机验收仍待完成。

2026-10-01 更新：Android code4 提供六套主题和「多电脑配置」，保留圆形话筒入口及黑白话筒图标；可覆盖同签名的原 Luma Preview / 言渡 code2/code3。逐电脑设置需要本轮新版 Desktop 接收端，9 月 30 日旧候选包需更新后才能显示该配置页。PhoneDeck 工程名、包名和旧候选文件名保留兼容，详见 [品牌说明](BRANDING.md)。实际安装及验收状态以 HANDOFF 为准。

这是新的统一桌面接收端。Windows/macOS/Linux 使用同一份手机协议、同一套本地识别引擎和最终文字记录。旧 Windows/Mac 接收端仍保留；两者占用相同端口，启动新版前请先退出旧接收端。

## 下载后使用

1. **Windows**：运行 `PhoneDeck-…-Setup.exe` 安装并打开；便携 ZIP 解压后双击 `Start-PhoneDeck.vbs`。允许系统防火墙在家庭/专用网络访问本程序。
2. **Mac**：把解压后的 `PhoneDeck.app` 放进“应用程序”再打开。预览包目前只有 ad-hoc 签名，首次打开可能需要在系统隐私与安全设置中允许。在“辅助功能”中允许 PhoneDeck 控制键盘；首次局域网权限提示也需允许。
3. **Linux**：Ubuntu 22.04/24.04 的 `.deb` 可由软件安装程序安装，随后从应用菜单打开；它安装 X11 输入所需的 `xdotool`。tar 包适合已有依赖的开发者。X11 可使用全局快捷键；Wayland 的输入和全局快捷键受桌面环境限制，见下方。
4. 打开后会显示本机控制页。**完整模型包**直接检查内置模型，**轻量包**点击一次“下载语音模型”（约190 MB）。无需安装 .NET、Typeless 或虚拟声卡。下载模型需要访问官方 Hugging Face；离线完整包无需此步骤。
5. Android 安装新候选 `Yandu-2.0.0-alpha.1-code4-multi-android.apk`，打开 **言渡**，在开始语音时允许麦克风权限。在“电脑列表 → 扫码配对”扫描电脑页二维码，核对校验码，在电脑点击确认。手机与电脑需在可互访的同一网络；发现失败时填写电脑页列出的地址。每台电脑分别扫码一次。由同签名 Luma Preview 或言渡覆盖升级可继续使用原配对；从旧外部输入法渠道首次接入需要重新配对。
6. 手机语音模式选择“点击”或“按住”，选定当前电脑，说话后结束。当前电脑本地识别最终文字。**开始时和结束时的输入焦点相同**才会自动填入；焦点改变则保留在记录里供复制。自动听写不会回车提交应用内容。
7. 电脑快捷键：先在手机开启“共享麦克风”，并勾选需要供音的电脑。默认 `Ctrl+Alt+Space` 开始/结束，`Ctrl+Alt+V` 按住说话；Mac 使用 `Control+Option`。每台电脑可在手机「多电脑配置」或本机控制页选择自己的两种快捷键。控制页的点击/按住按钮生成记录供复制。
8. 在手机“设置 → 同步文字”开启同步，勾选共享组。无论在哪台电脑触发，产生的**同一份最终文字**都会转发到组内电脑。接收的记录可以复制，不会自动填入或回车。

只有手机主动打开语音/共享后才采音。同步依赖手机页面仍在运行或共享麦克风前台服务在运行；手机退出/被系统终止后不会继续转发。每端记录最多100条、30分钟过期，仅在内存中。离线电脑在这个窗口内重连可重试；超出窗口或重启导致内存清空后不保证补发。共享组选择同时影响供音和同步目标，调整后请重开共享麦克风。

## 选择主题与逐电脑配置

手机进入「设置 → 外观主题」，选择墨水屏暖白、墨水屏深色、森林松绿、瓷白淡紫、燕麦陶土或天空雾蓝。首页和所有设置采用同一配色，关闭再打开仍保留选择；切换电脑不改变手机主题。电脑控制页也有外观选择，每台电脑可选不同配色，保存在当前浏览器，不同步到手机或其他电脑。

在手机「设置 → 多电脑配置」选择一台已配对电脑：

- 「语音与快捷键」可设置电脑名称、内置识别语言、自动填入和点击/按住快捷键，最后点「保存到这台电脑」。默认自动识别语言，也可选择中文、英语、日语、韩语、法语、德语或西班牙语。两种快捷键必须不同，组合从候选列表选择。设置保存到该电脑并在重启后保留。
- 「连接与同步」显示已确认连接，按稳定身份管理电脑，IP 改变不需要建一份新配置。共享组开关立即保存于手机，同时用于共享供音与最终文字同步；同步总开关在「设置 → 同步文字」。加入组不会切换当前输入目标。
- 关闭自动填入后，本机识别结果保留在电脑记录中供复制；开启后仍只在原输入焦点未改变时填入。其他电脑收到同步文字始终只存记录，不自动输入或回车。

进入电脑配置不会切换当前输入电脑，手机点击/按住模式保持原选择。电脑离线、正在听写、配置被另一端修改、快捷键不可用或保存失败时，不显示成功；草稿保留，按提示停止听写或刷新后重新编辑。缺少设置接口的旧候选提示升级；旧外部输入法接收端继续显示其输入法和连接设置。

电脑控制页的本机配置与手机操作同一份设置，保存需要本机空闲；更改语言、自动填入或快捷键仅影响这台电脑。手机共享组和同步总开关另存于手机，电脑表单不会更改它们。

## 常见问题

- 打不开控制页：退出旧 PhoneDeck 接收端，重新打开新版；手动打开 `http://127.0.0.1:8765/`。在控制页底部“退出接收端”可彻底结束运行。
- 手机连接失败：检查电脑系统防火墙、手机与电脑间网络隔离、电脑上显示的地址。原生 Android 只信任扫码固定的证书指纹；网页/PWA 则需按专门指引信任主电脑的公开根证书并访问 HTTPS 8768。仅在私有局域网允许所需接收端连接，不把回环 8765 暴露到网络。
- 模型下载失败：检查网络和存储空间后重试。模型使用固定版本、大小和 SHA-256，校验失败不会启用；可使用完整模型包。模型失败不影响扫码、授权和普通按键。
- Mac 输入失败：辅助功能授权给安装后的 PhoneDeck 应用，授权后重新打开。全局快捷键冲突时，控制页显示冲突状态；可在本机配置选择另一组合或使用手机按钮。Mac/Linux 的本轮快捷键改动仍待对应真机验收。
- Linux Wayland：语音识别和文字同步可用，自动填入不启用，因为 Wayland 不公开全局输入焦点。在支持 virtual-keyboard 协议的桌面可安装 `wtype`；GNOME Wayland 等环境不能保证普通按键输入。可在系统自定义快捷键绑定 `/opt/phonedeck/PhoneDeck.Desktop --toggle`，或使用控制页。按住模式需要系统分别支持按下/松开的绑定，否则使用点击模式。
- 老接收端不出现文字同步：旧版只共享 PCM/委托外部输入法，没有最终文字接口；升级本预览接收端并重新扫码。无需卸载旧接收端，可退出新版后再打开旧版。
- 文字内容差异：本地 Whisper 的中文识别、标点和速度需在你的硬件及麦克风上验证；此预览不承诺 Typeless 的文本润色效果。

## 版本边界

本版本是 `2.0.0-alpha.1`。它不参与旧版签名设备更新流程；不要把这些新包放入旧设备更新清单。目前不能宣称所有 Mac/Linux 桌面已实机验收。发布正式版前需要 Windows/Mac/Linux 的首次安装、权限、输入、语音、同步及断线验收。

Android分发渠道为 `com.codex.phonedeck.desktoppreview`，使用保存在所有者本地的固定签名。这个渠道默认扫码/TLS连接，不自动接入旧USB接收端或在启动时请求蓝牙权限；原Luma保留旧USB/蓝牙入口。CI的 `.preview` APK只供开发验收，临时debug签名不用于公开持续更新。Mac自行验收可按 [真机步骤](DESKTOP_ACCEPTANCE.md) 操作。

构建范围为 Windows x64、Mac Intel/Apple Silicon、Linux x64/arm64（匹配架构原生构建）。系统基线为 Windows 10/11 x64、macOS 14+、Ubuntu 22.04/24.04 桌面，其他 Linux 发行版先按技术预览对待；运行时支持范围参照 [Microsoft .NET 10 系统矩阵](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md)。Android 原生最低8.0；iPhone 采用本轮 PWA 前台预览，原生客户端尚未实现。

数据在当前用户的 `PhoneDeck-Desktop` 应用数据目录中，包含稳定身份、证书、授权、已下载模型及本机 `desktop-settings.json`。该文件按本机身份保存名称、语言、自动填入和快捷键；不要复制到另一台电脑来替代独立配置。识别文字和音频不写入该目录。撤销配对会停止对应手机的会话；重新配对即可恢复。不要把数据目录复制进 Git 或分发包。
