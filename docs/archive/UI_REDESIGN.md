## 1. 设计定位

这台手机 App 的本质不是"设置页"，而是一块**手持仪表台**：单手、离开视线 30cm、
每次使用 3–10 秒。设计目标按优先级排序：

1. **状态确定性**：一眼知道"连着哪台电脑、语音是否在采音"——不确定比难看更糟。
2. **动作速度**：常用快捷键和语音在拇指热区内，一跳直达。
3. **安静**：无渐变、无投影、无装饰（延续已确认方向），层级靠留白与字重，不靠线框堆叠。

## 2. 行为契约（重设计不得破坏）

来源 AGENTS.md「不可破坏的行为」与规格 §11：

- 底部语音操作区保持易触达；横屏双栏、大字体语音区独立滚动结构保留。
- 点击/按住两种语音模式、共享麦克风模式、"旧电脑更新请求不自动开麦"全部保留。
- 仅浅/深两主题；配置集中在手机；桌面保持轻量。
- 主要触摸入口 ≥48dp；状态用文字+颜色双重反馈；减少动画不影响反馈（UI-02/UI-03）。
- 语音快捷键从引擎档案动态读取；`DeckIconView` 系原创线性图形，不引入字体/图片/第三方资产。
- 主题切换只重绑视图，不重建会话所有者；切主题/旋转/恢复不重启采音（UI-03）。

## 4. 设计语言 v2：令牌

| 槽位 | 浅色 | 深色 | 用途 |

| surface | #FFFFFF | #1B1E24 | 卡片/语音坞 |
| surfaceSunken（新） | #F5F7FA | #14161B | 卡内凹槽（电平槽、输入框底） |
| text | #18202D | #F0F2F6 | 正文 |
| muted | #626D7C | #A7B0C0 | 次级文字 |
| primary（交互填充） | #2E5BD7 | #5B8DEF | 主按钮/开关/进度 |
| onPrimary | #FFFFFF | #101725 | 主按钮文字 |
| accent | #285ED4 | #A9C7FF | 文字链/选中态/焦点环（不用于填充） |
| primaryContainer（新） | #E7EDFB | #2A3560 | 选中卡片/模式 chip 底 |
| onPrimaryContainer（新） | #23408F | #D6E2FF | 容器上文字 |
| live（新，录音语义） | #C22B3B | #FF6369 | **仅**语音 ACTIVE/共享运行中 |
| onLive（新） | #FFFFFF | #20090C | live 上文字 |
| success / 容器 | #157347 / #E3F3EA | #79D2A3 / #1D2B24 | 连接在线 |
| warning / 容器 | #8A5B0A / #FBF1DF | #EAC078 / #33290F | 检测中/降级 |
| danger / 容器 | #BA3044 / #FBE7EA | #FFA0AA / #38181E | 失败/错误 |
| outline | #E1E5EB | #343B48 | 1px 细边（仅在无底色差处使用） |

深色主按钮从"淡蓝胶囊+深字"改为**饱和蓝填充+深字**（现 #A9C7FF/#142746 → #5B8DEF/#101725）：
淡蓝填充在深底上像"禁用"，饱和填充把唯一主操作顶到第一层级；对比度 8.73→5.55 仍达标。
`live` 与 `danger` 分离：红色只在"正在采音"出现，错误不再与录音抢同一语义。

### 4.2 字阶（替换 11/12/13/14/15/19 混用）

| 档 | 值/字重 | 用途 |
|---|---|---|
| display | 28sp ExtraBold | 品牌名"Luma" |
| title | 17sp Bold | 屏幕标题 |
| body | 14sp Medium | 卡片主文案、状态主行 |
| caption | 12sp Regular | 次级说明 |
| micro | 11sp Bold（全大写字母间距 0.5） | 状态标签 chip（仅短词：在线/录音中） |

### 4.3 间距与圆角（4dp 网格）

- 间距档：4/8/12/16/24/32；页面左右边距 20→16dp（3 列快捷键标签多 ~8% 宽度）。
- 圆角档：chip 全圆 / 控件与快捷卡 14dp（现 12）/ 语音坞 20dp（现 24）/ 主按钮全圆胶囊。
- 语音坞与页面同底色融合（去 outline 描边，靠 surface 与 background 的底色差分层），
  仅快捷卡在深色下保留 1px outline 补足底色差不足。
- 触摸：主语音钮 72dp（现 64），退格/回车/模式 48dp 不变；电平条高 4dp 融入状态行背景。
- 动效：仅 3 处——状态点呼吸（检测中 1.2s）、live 电平条实时、卡片按压涟漪（已有）。
  全部 `AnimatorCompat` 可关，不影响反馈（UI-02 减少动画要求）。

## 5. 信息架构 v2 与主控制台

结构从"页头+连接卡+网格+七行语音坞"收敛为**三条带**：状态带 → 动作带 → 语音坞。

```
┌────────────────────────────────┐
│ Luma                     ⚙ 设置 │ ← display 缩至 title；48dp 图标钮
│ ┌──────────────────────┐  ↻    │ ← 状态 chip（48dp 高，点击开设备 Sheet）
│ │ ● 在线 · DESKTOP-A · Wi-Fi │  │    ● 8dp 状态点 + body 计算机名 + caption 传输
│ └──────────────────────────┘   │    ↻ 48dp，仅重测不换目标
├────────────────────────────────┤
│ 快捷操作                 编辑   │ ← title→body Bold；编辑保留 48dp
│ ┌────┐┌────┐┌────┐             │
│ │保存 ││复制 ││截图 │  3 列     │ ← 72dp 卡、14dp 圆角、分类色 4dp 内联点
│ └────┘└────┘└────┘             │    空状态：线性图标+“添加第一个快捷键”
│ …（网格滚动区）                 │
├────────────────────────────────┤
│ ▎语音输入   [点击模式 ▾]        │ ← 状态行：live 竖条 + 模式 chip（可换）
│ ▔▔▔▔▔▔▔电平 4dp▔▔▔▔▔▔▔        │ ← 电平条嵌入状态行底，ACTIVE 时 live 色
│                                │
│      ( 🎤  按住说话 )           │ ← 唯一主操作：72dp 全圆胶囊
│                                │
│ [ 退格 ]  [ 回车 ]  [ 模式 ]    │ ← 48dp 三等分；模式入口从标题行移入
│ 就绪 · 手机麦克风 · 输入到 A     │ ← 合并反馈/麦克风/目标为一行 caption
└────────────────────────────────┘
```

变更逻辑：

- **去掉重复**：删除语音坞内"输入到"横向滚动行，目标只活在状态 chip 里（多机时点 chip 切换）。
- **主操作唯一**：语音坞里唯一大尺寸元素是主按钮；反馈、麦克风、目标合并为一行 micro/caption。
- **模式即按钮**：模式切换从标题行小字变为第三颗功能钮，热区从 ~0 变 48dp。
- 横屏保留"左网格滚动 + 右语音坞固定"结构，仅套用新令牌。

## 6. 状态系统（颜色+文字+图形三重，UI-01）

### 6.1 连接（状态 chip）

| 状态 | 点色/容器 | 文案 |
|---|---|---|
| 检测中 | warning + 呼吸 | 正在检测电脑端… |
| 在线 | success | 在线 · {计算机名} · {USB/Wi-Fi/蓝牙} |
| 离线 | danger 容器 | 离线 · {计算机名} · 上次 {mm:ss} |
| 未配置 | muted | 尚未配对电脑 |

### 6.2 语音（主按钮 + 状态行，映射 `updateVoiceControls()` 真实状态机）

| 状态 | 主按钮 | 状态行 |
|---|---|---|
| 就绪 | primary，"按住说话/点击说话" | 就绪 · 模式 · 麦克风 |
| 启动中 | primary 45% 禁按压，"取消"可点 | 正在唤醒 {引擎}…（CONNECTING 电平） |
| 采音中 | **live 填充**，"松开结束/点击停止" | ● 录音中 · 实时电平条 live 色 |
| 暂停 | live 45%，"已暂停" | 已暂停 · 点按继续 |
| 停止中 | outline，等待 | 正在收尾…（保留尾音语义，MIC-03） |
| 失败 | danger 容器一次反馈 | 发送失败 · {原因} · 可重试 |
| 共享运行 | live 填充，"停止共享" | 共享中 · {N} 台电脑 · 实时电平 |

语音坞整体在采音中加 8% live 底色晕染（背景 tint，非发光），停止即褪——
全局唯一的"正在采音"视觉信号，满足"audio.streaming 不等于在识别"的诚实呈现。

## 7. 其余屏幕

- **设备 Sheet**（状态 chip 点击）：底部滑出列表，卡片含平台线性图标、名称、
  在线点、当前 primaryContainer 高亮；长按管理（忘记/重命名）保留；右上"添加电脑"。
- **设置首页**：分组列表（使用偏好/连接与传输/语音引擎/维护），行高 56dp，
  图标 24dp 线性；移除二级标题重复。
- **电脑设置**：保留设备卡 + 输入法/连接分页与草稿行为（2026-09-21 已验收），
  仅套用字阶/间距/容器令牌，不改交互。
- **快捷键编辑/按键选择器**：同上，纯令牌迁移。
- **Windows 状态窗**：不改结构（轻量红线），只对齐语义命名与状态三色，
  状态点尺寸对齐 8dp，深色主操作同步改饱和填充。
