# 扫码配对与共享组使用指南

> 已归档（2026-10-06）：扫码配对已移除，现在同一 Wi-Fi 的电脑会出现在手机首页「附近 · 点按连接」，核对四位校验码后在电脑上允许。当前步骤见 [Windows 部署](../guides/WINDOWS_WIFI_DEPLOY.md) 和 [macOS 接收端](../guides/MACOS_SETUP.md)。

> 适用于 2026-09-30 之后的源码构建（M1-A/M1-B 能力）。面向普通用户的图文流程。

## 一、把手机连接到电脑（扫码配对）

前置：手机与电脑在**同一局域网**（同一 Wi-Fi/路由器）；电脑已运行 PhoneDeck 接收端
（托盘图标可见）。

1. **电脑端**：右键托盘图标 → 「配对新手机…」，弹出配对窗口（二维码 + 手工码 + 校验码）。
   窗口有效期 **120 秒**，可点「重新生成」。
2. **手机端**：打开 PhoneDeck → 点顶部状态条 → 「扫码配对新电脑」（或空列表时的
   「扫码配对」）→ 对准电脑屏幕上的二维码。
   - 相机不可用？在电脑配对窗口读 **手工码**（8 组 4 字符），在手机配对流程里选
     「输入电脑地址」手动输入电脑 IP（电脑状态窗可见）。
3. **电脑端确认**：手机提交后，配对窗口出现确认卡（显示手机型号 + 校验码）——
   **请核对手机侧显示的校验码与窗口一致**（防止他人抢配），点「确认配对」
   （30 秒内有效）。
4. 完成：手机提示「配对成功，并已通过连接验证」。此手机获得**独立凭据**，
   电脑可单独撤销它而不影响其他手机。

安全说明：二维码内含一次性材料，用后即废；配对必须电脑端本机确认；材料与凭据
不写日志。失败 5 次窗口自动关闭，需重新开窗。

## 二、共享麦克风（同时给多台电脑供音）

共享组是**你显式勾选的电脑集合**——新配对的电脑**不会自动**收到你的麦克风音频。

1. 手机 → 状态条 → 「⚙ 管理共享组」→ 勾选要接收的电脑 → 完成。
2. 底部语音区切到共享模式，开始后同时向组内所有在线电脑供音；勾选变更下一轮
   探测生效（移除即停止对该电脑发送）。
3. **全部组内电脑离线超过 15 秒**：手机自动停止采集（省电/防误采）；网络恢复后
   重新开始即可。

## 三、旧版升级（共享令牌 → 独立凭据）

用旧版本配对过的手机连接后，会提示「升级为独立凭据」：
- 升级无需重新扫码，点确认即可；
- 旧令牌在迁移窗口内继续兼容；升级经验证成功才替换，失败不影响现有使用；
- 升级后每台手机凭据独立，电脑端可单独撤销任意一台。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 扫码后提示"配对窗口未开启" | 电脑端窗口已过期（120s），重新点「配对新手机…」 |
| 提示"失败次数过多" | 连续 5 次失败关窗，重新开窗并核对手工码 |
| 发现不了电脑 | 跨网段/AP 隔离/VPN：用手工码路径手动输入电脑 IP |
| 想断开某台手机 | 电脑端管理接口撤销该手机（凭据立即失效并断流）；手机端"忘记"只删本机记录 |
