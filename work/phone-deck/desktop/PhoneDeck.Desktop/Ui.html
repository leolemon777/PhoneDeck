未开始

电脑快捷键：Ctrl+Alt+Space 开始/结束；Ctrl+Alt+V 按住说话。Mac 使用 Control+Option。

手机主动开启后才会采音。关闭这页后，接收端仍在运行。

同步文字

手机「设置 → 同步文字」开启同步并选定共享组。最终文字保持一致；其他电脑只接收记录。手机听写或电脑快捷键可填入开始说话时的输入框；焦点改变则保留记录。此页按钮生成记录供复制。

记录仅保存在内存中，30分钟过期；退出接收端后清空。
