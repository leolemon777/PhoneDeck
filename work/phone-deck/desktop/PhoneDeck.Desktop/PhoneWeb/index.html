添加到主屏幕

iPhone · Safari

  1. 在 Safari 打开电脑提供的手机地址，完成安全连接与配对。
  2. 轻点浏览器的「分享」，选择「添加到主屏幕」。
  3. 从主屏幕打开言渡，点击话筒时允许使用麦克风。

安卓 · Chrome

打开浏览器菜单，选择「添加到主屏幕」或「安装应用」。菜单名称因浏览器而异。

添加后首次打开若仍未配对，请在电脑重新生成手机连接链接，回到主屏幕里的言渡，点「电脑 → 连接这台手机」粘贴并确认。浏览器与主屏幕 App 的存储可能独立。

第一次见面

连接与麦克风权限

先建立安全连接

让手机与电脑处于同一网络，从电脑控制页打开「手机网页」。麦克风需要 HTTPS 安全连接；跳过浏览器警告不等于已建立可信连接。

使用电脑的本地证书

按电脑端的手机连接指引下载并安装本地证书，仅信任你自己电脑提供的证书。iPhone 安装后，还需在「设置 → 通用 → 关于本机 → 证书信任设置」启用该根证书的完全信任。

手机访问的地址必须与证书一致。证书过期、网络地址改变或信任未完成时，请回电脑端重新检查。

麦克风被拒绝时

在浏览器的网站设置中允许麦克风，再回到本页重新尝试。iPhone 也可在「设置 → App → Safari」检查麦克风权限。

网页无法保证锁屏后继续供音。为避免手机显示停了、电脑仍在等声音，离开前台时会结束本次采音；返回后需手动重新开启。
